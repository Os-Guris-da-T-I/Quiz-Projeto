## 🎯 Objetivo

Criar um quiz em que a pessoa possa responder perguntas sobre
tecnologia, conferir se acertou e aprender um pouco mais com as
explicações apresentadas no final de cada resposta.

## 🧠 Como o quiz funciona

Na versão atual, o usuário pode escolher entre três níveis:

-   **Modo Fácil:** mostra a dica durante a pergunta.
-   **Modo Normal:** permite que o usuário veja uma dica quando quiser.
-   **Modo Difícil:** esconde a dica e inicia um cronômetro de 1 minuto
    e 50 segundos para cada pergunta.

O quiz possui 15 perguntas cadastradas no JavaScript. Os assuntos
incluem linguagens de programação, HTML, CSS, SQL, Git, hardware,
algoritmos, lógica de programação e desenvolvimento de jogos.

Quando o usuário escolhe uma alternativa, o sistema informa se a
resposta está certa ou errada e apresenta uma explicação. No final, é
exibida a quantidade de questões respondidas corretamente. Também existe
um botão de acessibilidade planejado para ativar recursos como alto
contraste e ajustes visuais.

## ▶️ Como executar

Para testar a versão HTML e JavaScript no computador:

1.  Baixe ou clone o repositório.
2.  Deixe o `index.html`, o `script.js` e o `style.css` na mesma pasta,
    caso o HTML continue usando os caminhos atuais.
3.  Confira se o arquivo JavaScript está salvo como `script.js`, porque
    esse é o nome chamado no HTML.
4.  Abra o arquivo `index.html` no navegador.
5.  Escolha um nível de dificuldade e responda às perguntas.

Também é possível abrir a pasta no Visual Studio Code e usar a extensão
**Live Server** para visualizar a página no navegador enquanto o grupo
faz alterações.

> Para a aparência funcionar como esperado, será necessário criar o
> arquivo `style.css`, que é referenciado pelo HTML. A execução do
> código em C e a integração com JSON ou com a API de segurança dependem
> de como essas partes forem conectadas ao projeto.

## 🧩 Organização do código atual

### HTML

O arquivo HTML define três áreas principais:

-   **Tela inicial:** apresenta o título e os botões de dificuldade.
-   **Tela do quiz:** mostra a pergunta, as alternativas, a dica, o
    cronômetro e a explicação.
-   **Tela final:** apresenta a pontuação e permite voltar ao início.

### JavaScript

O arquivo JavaScript contém:

-   Uma lista com 15 perguntas e quatro alternativas por questão.
-   A indicação da alternativa correta.
-   Dicas e explicações para as respostas.
-   A contagem de acertos.
-   A troca de perguntas.
-   O cronômetro do modo difícil.
-   Os eventos dos botões de dificuldade, dica, próxima pergunta e
    reinício.

## 🔐 Segurança e cuidados

Como o projeto também prevê o uso de uma API de segurança, essa parte
precisa seguir o que foi definido pelo professor e pelo grupo. Antes de
concluir a documentação, é importante registrar qual API foi escolhida,
o que ela protege e como foi integrada.

Alguns cuidados gerais para o projeto:

-   Não colocar senhas, tokens ou chaves privadas diretamente no código
    público.
-   Não publicar dados pessoais de colegas ou usuários.
-   Validar os dados recebidos de outras fontes, como arquivos JSON ou
    APIs.
-   Explicar no README quais recursos de segurança estão realmente
    funcionando, sem apresentar funcionalidades planejadas como se já
    estivessem prontas.
